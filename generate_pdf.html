1. Core SaaS & Super Admin Platform

Mengelola siklus hidup Tenant, penentuan Paket Langganan & Kuota, Verifikasi Dokumen KYC, Payment Gateway Otomatis (QRIS / Virtual Account), serta penegakan isolasi data (Multi-Tenant Partitioning).

    subgraph SuperAdmin["👑 SaaS Super Admin Hub"]
        A1[Tenant Management]
        A2[Plans & Pricing]
        A3[KYC Verification]
        A4[Finance & Revenue]
    end

    subgraph CoreAuth["🔐 Auth & Multi-Tenant Engine"]
        AUTH[AuthController / Sanctum]
        T_SCOPE[HasTenant Trait / Global Scope]
        SUB_MID[CheckSubscription Middleware]
    end

    subgraph Billing["💳 Billing & Payment Engine"]
        SUB_REQ[SubscriptionRequest]
        INV[TenantInvoice]
        PG_SVC[PaymentGatewayService]
        WEBHOOK[Payment Webhook Callback]
    end

    subgraph Databases["🗄️ Partitioned Database"]
        DB_TENANTS[(tenants)]
        DB_INVOICES[(tenant_invoices)]
        DB_DATA[(Tenant Data Tables)]
    end

    A1 -->|Kelola Tenant| DB_TENANTS
    AUTH -->|Auto-Seed Data Awal| DB_TENANTS
    AUTH -->|Inject tenant_id| T_SCOPE
    T_SCOPE -->|Filter Query Otomatis| DB_DATA
    SUB_MID -->|Validasi Expiry Date| DB_TENANTS
    SUB_REQ -->|Generate Invoice| PG_SVC
    PG_SVC -->|Simpan Invoice Unpaid| INV
    INV --> DB_INVOICES
    WEBHOOK -->|Settlement QRIS / VA| PG_SVC
    PG_SVC -->|Perpanjang Masa Aktif| DB_TENANTS
Multi-Tenant Isolation Menggunakan `TenantScope` global otomatis pada level query database Eloquent.
Instant Settlement Engine Aktivasi paket instan via webhook QRIS & 3 Virtual Account bank nasional.
